# Contributing

Contribution policy for the whole Assessment-Models organization lives in the [organization-wide CONTRIBUTING](https://github.com/Assessment-Models/.github/blob/main/CONTRIBUTING.md).

For this template:

- Normative changes belong in [maturity-model-standard](https://github.com/Assessment-Models/maturity-model-standard); this repository implements, it does not legislate. Propose standard changes there first.
- Keep the template self-consistent: `model.yaml` ↔ `VERSION` ↔ `README.md` status line ↔ `standard.yaml` must always agree, because the template's own CI validates exactly that.
- Scaffolding fixes that keep the template aligned with the standard's current published version are welcome.
